# HistoryVulcan Host Distribution

The release pipeline produces the executable host, Console CLI, and Core, Services and ServiceHost assemblies. Projects do not produce NuGet packages.

Consumer documentation is authored in `b-Office/package` and generated into `z-Publish/docs`. See the [module API](../b-Office/package/模块API.md) for package requirements and migration, and the [freeze contract](../b-Office/current/冻结合同.md) for the current API baseline.
