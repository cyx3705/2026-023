核对方法：读取宿主源码、测试、Diana 已发布文档通道，并用 System.Reflection.Metadata / PEReader
只读分析已部署模块的 TypeReference/MemberReference 与相关命令字符串，不加载或执行模块程序集。

| 保留项 | 原因 |
| --- | --- |
| CommandBus.FrontendExecutor / RemoteExecutor / ShouldUseRemoteCommand | Aurora 实际设置这些委托，读取 RemoteExecutor；是通用集成合同 |
| ModuleHost.Modules / ModulesDirectory / InstallPackage / RemovePackage / Reload | Aurora 已部署程序集实际引用 |
| 现用目录 DTO、设置与 AppPaths 接口 | Aurora、Janus、Mercury 及已发布消费合同存在引用 |
| WPF 程序集解析、可回收 ALC、pinned 语义与卸载 | 模块实际运行需要；不属于 Web/MCP 网关实现 |
| IModuleDiscoverySource、身份/路径/依赖数据 | 通用模块接入与包解析边界；运行组合固定使用 RuntimeModuleDiscoverySource |
| vulcan.app.get/set、module.roots/open 与现用模块管理命令 | 保持现用命令合同；roots 只查询并拒绝切换目录，runtime 暴露另受四条清单约束 |
