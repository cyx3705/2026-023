## 目录与真值

| 路径 | 职责 | 编辑边界 |
| --- | --- | --- |
| b-Code-HistoryVulcan | Core、Services、ServiceHost、App、Cli 源码 | 产品实现；发布引擎也在 Services |
| b-Code-Tests | 本仓测试 | 不跨仓 ProjectReference |
| b-Code-Eng | API 基线、发布登记表、消费文档清单与可选安装器输入 | 不复制发布引擎 |
| b-Office/current | 现行合同 | 只保留有效要求 |
| b-Office/package | 消费文档编辑源 | 发布前在此修改 |
| b-Office/history | 旧合同、演进与验证证据 | 历史不覆盖当前事实 |
| z-Publish | 当前候选的 host/docs/manifest/SHA | 仅发布流程生成，不直接编辑 |
| z-Publish/history | 不可变发布归档 | 不覆盖或手改 |
| artifacts、bin、obj | 生成数据 | 排除日常源码上下文 |

活动目录以根 project.manifest.json 为准；新增活动根、依赖或验证命令时同步清单。
根 HistoryVulcan.sln 是唯一解决方案；global.json、nuget.config、Directory.Build.props 与 manifest 保持工具约定位置。
机器专用 Directory.Build.user.props 不入库。

## 消费与发布

跨项目先 diana.docs.catalog，再读取返回的已发布通道。仅工具未暴露或失败时降级到目标正式 z-Publish/docs；
不读取邻接项目 current/package/worktree。本仓 package 是编辑源，生成 docs 不手改。

桌面界面与视觉规范归 Aurora，命令工作台/快捷键归 Mercury，Web/MCP 归 Portunus。本仓只描述所有者和消费边界。
正式发布由宿主进程内管线整体生成快照并校验文件清单与 SHA，不以 PowerShell 发布脚本为引擎。
CI 只验证；提交、推送、打标签、正式发布与部署均须另行授权。

旧现行合同在[5.2.1 原文归档](history/5.2.1-现行合同归档.md)，本轮证据在[5.3.0 实施记录](history/5.3.0-修复与清理证据.md)。
