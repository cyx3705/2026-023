## 编辑位置

活动目录及生成/归档目录由 [project.manifest.json](../project.manifest.json) 声明。

| 路径 | 编辑边界 |
| --- | --- |
| b-Code-HistoryVulcan / b-Code-Samples | 产品源码 / 起步示例 |
| b-Code-Tests / b-Code-Eng | 本仓测试 / API 基线与发布输入 |
| b-Office/current / b-Office/package | 现行维护合同 / 消费文档编辑源 |
| b-Office/history | 历史背景，不覆盖现行行为 |
| z-Publish / z-Publish/history | 生成候选 / 不可变发布归档，不能手改 |
| artifacts、bin、obj | 生成数据，排除日常维护上下文 |

新增活动根、依赖或验证命令须同步 manifest；机器专用配置不入库。消费文档由进程内发布管线从 package 生成。
跨项目阅读及桌面观察遵循 [AGENTS](../AGENTS.md) 的 Diana 入口，不读取邻接项目 current/package/worktree。
