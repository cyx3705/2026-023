# HistoryVulcan 有效决策

本文只保留当前约束。被替代的实施过程与原决策全文见[5.2.1 合同归档](../history/5.2.1-现行合同归档.md)，历史编号不重新分配。

## DEC-060 5.3.0 修复与迁出遗留清理

日期：2026-09-06。用户明确指定源码 5.3.0，保留冻结标签 v5.1.2，授权删除本轮过期公开成员和实现。
这是一项明确的兼容变化例外：删除通常需要主版本，本轮按批准的 5.3.0 执行，不作为今后任意删除的先例。

清除 ZModuleDiscoverySource、ModuleHost 旧目录构造/切换/确认源/选择性命令分支、ModuleDiscoveryEntry.McpExposure、
MCP 配置迁移与专属注册方法、ShellRelayConfirmation 和 Portunus runtime 指令。构造函数缩减登记为旧签名移除和新签名加入。
原始 Shipped 保持不变，精确符号清单由 Unshipped 和 5.3.0 基线共同约束。

包事务区分备份、就位和提交，旧 data 复制到新包后仍留在备份。回滚失败保留恢复路径，提交后清理失败不回滚。
Attach 失败不发布任何模块命令，热安装失败回滚；同包修复以健康实例为幂等条件。进度沿用请求敏感值过滤。

配置入口保持 vulcan.app.get/set 和原存储，取消 mcp.* 限制，全部回执统一遮蔽敏感值；不删除用户现有文件和键。
runtime 只保留模块 list/ready/reload/install；不放宽用户管道、握手和动作批准，不新增模块协议。

删除前核对范围为宿主源码、测试、已部署模块元数据引用和正式消费合同。
已观察到 Aurora 使用 FrontendExecutor、RemoteExecutor、ShouldUseRemoteCommand、模块管理/目录 DTO/设置/路径合同，故保留。
未观察到本轮删除接口的部署消费引用；此结论限于已核对版本，不能推断未知第三方没有依赖。
Web/MCP 由 Portunus、界面由 Aurora 所有；WPF 解析与可回收 ALC 不属于迁出网关，继续保留。

## DEC-056 冻结基线

宿主 5.1.2 已冻结注册器、命令总线与开发/发布合同；标签仍为 v5.1.2。
内部重构和正确性修复可以继续。API 删除、改签与新增必须版本登记、消费说明及门禁；本轮特例见 DEC-060。

## DEC-057 / DEC-059 接入与快照

按 manifest 的 dependsOn 逐个接入，成功一个发布一个；整轮完成提供就绪状态和声明式 host.ready 通知。
单包热装不发整轮通知。按模块卸载的快照清除集中在 Snapshot.ForgetModule，待接入项也必须清除。
5.3.0 将失败语义补齐：失败实例可查询但不可执行其命令。

## DEC-058 单次解析和公开面清理

命令请求只解析一次；敏感规则来自参数和键语义，不按具体命令名建立秘密清单。
5.2 已批准的零消费公开成员删除记录继续保留，不重写 Shipped。

## DEC-052 / DEC-053 / DEC-054 / DEC-055 开发恢复能力留在宿主

宿主不提供模块领域抽象；模块开发/发布引擎是宿主基础能力，不再做成模块，不用 PowerShell 充当引擎。
离线 CLI 与受限 runtime 管道分离，runtime 不可达不得降级为离线成功。
宿主禁止走模块开发三步；拒绝替换当前进程运行目录，自替换由人工在部署阶段操作。
模块工作区流程以[模块开发手册](../package/模块开发手册.md)为准，不在本文件复制流程。

## DEC-040 / DEC-043 / DEC-039 固定运行区与独立仓库

每个编号项目是独立 Git 仓库，本仓 CI 不引用邻接实现。
模块只从固定运行区完整包发现，监听该运行区；候选与运行包分离。热更新不以停止宿主为步骤。

## DEC-049 / DEC-050 / DEC-051 所有权

桌面界面归 Aurora，命令工作台与快捷键归 Mercury，Web/MCP 归 Portunus，提示治理由模块负责。
宿主只保留通用模块生命周期与命令集成。命令域跟随实现所有者；宿主已存在的界面生命周期命令通过 FrontendExecutor 转交界面模块。

## DEC-025 / DEC-023 命令与门禁

三段业务命令和两段直接方法并存；域归属由注册表/模块 owner 决定，模块域去 History 前缀。
本仓门禁不依赖模块业务测试，不恢复跨仓 ProjectReference。

## DEC-005 / DEC-007 / DEC-008 真值、验证与工具链

current 为现行规则，package 为消费编辑源，history 为只读背景，z-Publish 为生成快照。
固定 SDK、锁定依赖与格式规则；CI 只执行还原、构建、测试、格式和 API 门禁，不执行正式发布或 Git 写入。
