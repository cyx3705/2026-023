# HistoryVulcan 验证合同

适用源码：**5.3.0**。冻结标签仍为 **v5.1.2**。本仓验证不依赖邻接模块源码、固定模块名单或运行区用户数据。

## 门禁

| 编号 | 内容 | 验收 |
| --- | --- | --- |
| VERIFY-FAST | 先运行直接相关测试；合同/API 修改运行 ReleasePipelineTests | 相关行为及合同无失败 |
| VERIFY-FULL | 锁定还原、Debug/Release 构建和测试、格式检查 | 两配置零警告零错误、全测通过、格式无差异 |
| VERIFY-API | QualityGatesPassOnThisRepository | 三份 Unshipped 与 5.3.0 批准基线一致；删除均可追溯至 Shipped |
| VERIFY-CONTRACT | HostProjectContractPassesOnThisRepository | manifest/版本一致、声明链接有效、现行 REQ 唯一、验收测试存在 |
| VERIFY-BOUNDARY | HostArchitectureTests、RuntimePipeServerTests | 无网关实现和旧发现类型；runtime 严格四条，Portunus 指令被拒绝 |
| VERIFY-CLI | CommandLineEntryTests、RuntimePipeServerTests | 离线/运行时分离、握手、批准和单一 JSON 回执 |
| VERIFY-TRANSACTION | ModulePackageTransactionTests、RuntimeModulePackageTests、发布恢复测试 | 完整载荷、用户数据与运行快照恢复；恢复失败留备份；提交后清理不回滚 |
| VERIFY-STARTUP | ModuleStartupOrderTests、ModuleHostContextTests、RuntimeModulePackageTests | 空启动、坏包隔离、接入失败无命令、重试和连续升级、邻居可用 |
| VERIFY-REDACTION | CommandProgressRedactionTests、FreezeBlockerTests、HostSettingsTests | 命名/位置参数、同步/异步/并发进度、异常和配置列表不泄密 |
| VERIFY-CI | 根 .github/workflows/historyvulcan-freeze-gate.yml | 只还原、构建、测试、格式和 API/合同校验 |
| VERIFY-DEPLOY | 另行授权后候选/部署与真机联调 | 宿主和 CLI 版本、清单、SHA、消费模块及 UI 行为一致 |

需求的精确验收方法在[技术合同](技术合同.md)中定义；门禁只解析现行 REQ 标题及「验收」标记。
历史记录、迁出说明和 PublicAPI 删除记录不采用关键词清零。

## 本地执行

```powershell
dotnet restore .\HistoryVulcan.sln --locked-mode
dotnet build .\HistoryVulcan.sln -c Debug --no-restore
dotnet test .\b-Code-Tests\HistoryVulcan.Tests\HistoryVulcan.Tests.csproj -c Debug --no-build --no-restore
dotnet build .\HistoryVulcan.sln -c Release --no-restore
dotnet test .\b-Code-Tests\HistoryVulcan.Tests\HistoryVulcan.Tests.csproj -c Release --no-build --no-restore
dotnet format .\HistoryVulcan.sln --verify-no-changes --no-restore
```

API 与合同门禁均包含在全量测试中，可用 FullyQualifiedName 过滤单独运行。
测试只在隔离临时目录与唯一名称的测试管道上操作，不启动/停止正式宿主、不修改 AppData 用户数据。
测试删除操作必须在测试自己的临时目录中；锁文件模拟共享冲突后须释放句柄。

## 场景要求

包事务覆盖暂存失败、目录锁、备份失败、新包加载失败、数据复制失败、回滚失败和提交后清理失败。
断言完整文件内容或校验清单、原始 data 和 Attached/命令快照，不能只检查 manifest 存在。
发布回滚失败必须保留恢复备份；成功提交后的清理失败只能报告残留路径。

接入覆盖 Attach 前抛错、部分注册后抛错、不健康同包重试、连续升级和邻居可用。
仍有价值的生命周期测试改用完整 manifest 包；项目库扫描/旧路径迁移/远程确认测试随行为退役。
配置测试验证通用键、敏感值、现有值保留。内部 InvokeAsync 保持 Data 语义，同时验证进度脱敏。

## 发布与真机边界

本轮不运行发布命令，不生成或修改 z-Publish。候选构建需显式 worktree；省略 worktree 是正式流程，不能写成普通验证命令。
宿主自身禁止 dev.start/submit/finish；自替换需要人工在已停止的目标之外执行，本轮不停止宿主。

正式部署后另验：Aurora 界面接管确认、真实 WPF 卸载、host.ready 页面发现、Portunus 自持传输与配置消费。
图形观察先 Diana windows/capture 并实际读取 PNG，保留尺寸、捕获方式和 SHA；无授权不接管前台。
这些项目不能由单元测试结果替代，源码交付时明确标为未执行。
