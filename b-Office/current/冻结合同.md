# HistoryVulcan 宿主冻结合同

源码：**6.0.0**；现行冻结线：**v6.0.0**（2026-10-01 按 [DEC-071](有效决策.md) 收口统一模块契约）。

## 基线

冻结的是宿主给模块的统一契约：一条总线（`ICommandBus` / `ICommandRegistrar`）、一个上下文（`IModuleContext`），加上开发/发布总线的命令面。
Core 的公开类型就是[模块 API](../package/模块API.md) §1 的白名单，Shipped 即全部公开面，三份 Unshipped 与 `b-Code-Eng/public-api-baselines/6.0.0/` 均为空；
Services 与 ServiceHost 没有公开类型。宿主指令的 Data 是写明的 JSON 形状，字段只增不减。

v5.4.0 是上一条冻结线（DEC-063），其结转前文本保存在 `public-api-baselines/5.4.0/` 的 PreFreeze 文件。
界面、Web/MCP 网关和模块领域抽象不属于宿主职责，见[项目概览](项目概览.md)。

## 变更纪律

- 内部重构可以继续；正确性修复保持签名并补回归测试。宿主内部类（总线、注册表、日志、模块宿主）可以随意改，不影响任何模块。
- 新增公开 API 先推进版本，再登记 Unshipped、批准基线、白名单与消费摘要；通用集成优先使用命令名与事件主题。
- 载荷形状只增不减；删字段、改语义或改签走主版本并提供迁移说明。
- Git 标签和正式发布须明确授权。源码冻结不代表已创建标签或部署。

验收按[验证合同](验证合同.md)执行。已部署引用核对不能替代正式发布前的消费模块与真机联调。
