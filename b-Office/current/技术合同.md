# HistoryVulcan 技术合同

适用源码：**5.3.0**；冻结基线：**5.1.2 / v5.1.2**。只列宿主仍拥有的要求。
每个 REQ 仅在本文件定义一次，验收行引用本仓测试方法，项目合同门禁校验编号与引用。

## 架构

宿主由 Core、Services、ServiceHost 和 App/Cli 组成。模块接入共享命令总线；WPF 界面由 Aurora 装入同一宿主。
Portunus 自持 Web/MCP 协议与监听。宿主只维护当前用户命名管道供本地 runtime CLI 管理。
消费方集成见[模块 API](../package/HistoryVulcan_模块API.md)，冻结规则见[冻结合同](冻结合同.md)。

### REQ-PKG-001 独立宿主与仓库边界

宿主、CLI 和三份合同程序集由本仓解决方案构建。不得通过跨仓 ProjectReference 依赖模块实现。
源码、manifest 和版本源一致；生成快照不作为源码编辑面。

验收：`ReleasePipelineTests.HostProjectContractPassesOnThisRepository`。

### REQ-CMD-001 统一命令总线

命令经注册表解析、参数校验、确认与线程编组后执行；异常转为失败回执。命令解析结果在一次请求中复用。
Readonly 表达写入性，Level 表达确认，HiddenReason 表达隐藏原因；它们是通用元数据。
参数、注解、目录 DTO 保持现用消费合同。

验收：`CoreFreezeContractTests.CommandBusBindsTypesAndEnforcesConfirmationGate`。

### REQ-CMD-010 分类与域聚焦

三段命令为域/类/方法，两段命令为域内无类直接方法。显式 CommandClass 优先。
已注册域是绝对名解析真值，不硬编码模块域表。域聚焦只为非绝对输入补前缀，界面筛选属于消费方。
当前宿主命令类别由实际注册表决定，不保留 Web/MCP/UI 旧类作为宿主实现承诺。

验收：`CommandTaxonomyContractTests.TwoSegmentNamesAreClasslessDirectMethods`。
验收：`CommandTaxonomyContractTests.DomainFocusResolvesAbsoluteNamesWithoutPrefixing`。

### REQ-CMD-011 模块拥有自己的命令域

模块域由所有者名称剥离 History 前缀并小写推导；模块声明的 Domain 不得越过其所有者。
无品牌前缀的名称原样小写；空主体保留 history。

验收：`CommandTaxonomyContractTests.ModuleOwnedCommandsUseTheNormalizedDomainNotTheManifestName`。

### REQ-CMD-014 请求级敏感值脱敏

按命名参数、位置参数定义及通用配置键识别敏感值；回显、返回消息、异常、执行事件和进度使用同一请求的值集合。
同步、异步和并发进度不能泄露本请求秘密或串用其他请求状态。语法错误遮蔽命令名之后的输入。
ExecuteAsync 是审计入口；InvokeAsync 不回显、不入历史、不触发 Executed，保留内部 Data 载荷，但其进度日志仍脱敏。
此保证针对总线日志，不代替模块自行写日志时的脱敏责任。

验收：`CommandProgressRedactionTests.ConcurrentProgressMasksNamedAndPositionalSecrets`。
验收：`FreezeBlockerTests.CommandExceptionsDoNotExposeSensitiveValues`。
验收：`CommandBusQuietInvokeTests.QuietInvokeDoesNotRaiseExecuted`。

### REQ-CFG-001 通用配置与存储

vulcan.app.get/set 保持 key/value 参数和原 service 配置存储位置，接受任意非空键。
读取、列举、写入回执统一遮蔽 token/password/secret/privatekey/passwd/connectionstring/code 等敏感键。
既有配置文件与 mcp.* 等旧键不迁移、不自动删除；解释权在消费模块。
损坏配置保留可恢复副本，写入采用原子替换。

验收：`HostSettingsTests.GenericSettingsMaskSensitiveReadWriteAndList`。
验收：`QualityRemediationTests.CorruptedSettingsArePreservedAndSubsequentWritesAreAtomic`。

### REQ-MOD-002 最小模块上下文

IModuleContext 只提供 Bus 和 RegisterCommands，不提供设置、日志、数据或 UI 领域抽象。
模块接入用命令名集成；同包反射命令与显式注册命令统一归所属模块。

验收：`ModuleHostContextTests.ContextAwareModuleRegistersCommandsOnlyThroughTheBus`。

### REQ-MOD-005 卸载与资源释放

卸载只移除目标模块及其命令，保留邻居模块；Dispose/Reload/Unload 的拆除路径均释放实例和可回收程序集上下文。
module.unload 只改运行快照；remove/uninstall 才删除完整运行包及数据。

验收：`ModuleHostContextTests.ModuleInstancesAreDisposedOnEveryTeardownPath`。
验收：`ModuleHostContextTests.UnloadRemovesTheModuleAndItsCommandsWithoutReloading`。

### REQ-MOD-006 固定运行区和完整包发现

运行发现只枚举固定 Modules 的直属包，校验 schema/type/身份/路径和完整 SHA256SUMS。
artifact/docs/deps 必须是包内不可变文件；data/history 不进入校验清单，不能藏入可执行入口。
重复身份拒绝全部候选，坏包保留诊断并继续邻居。项目库、旧路径迁移、裸 DLL 与旧槽发现退役。
旧 manifest 的额外 MCP 字段被忽略，不参与宿主判断。

验收：`RuntimeModulePackageTests.DiscoveryRequiresCompleteChecksumsAndRejectsTraversalAndDuplicates`。
验收：`ModuleManifestTests.OldGatewayMetadataIsIgnoredAndLegacyDiscoveryPathsAreInactive`。
验收：`ModuleHostContextTests.EmptyRuntimeDirectoryStartsWithoutModules`。

### REQ-MOD-007 WPF 解析与热重载

可卸载模块装入可回收 ALC；默认上下文的 XAML 解析只返回已经装入该 ALC 的程序集。
pinned 包继续使用默认上下文，不承诺热替换。保留 UI 线程编组与文件监听去抖，不把 WPF 依赖误当旧网关遗留。
固定运行区文件变化触发重载，发布安装通过事务协调监听。

### REQ-MOD-008 完整清除目标快照登记

按模块卸载统一清除命令、元数据、待接入项、实例与上下文登记，不得让旧 PendingAttach 在下一次安装再次接入。

### REQ-MOD-009 接入次序与就绪屏障

原重复的「REQ-MOD-008 装载次序」改为本编号。dependsOn 只约束次序，不是硬依赖；缺失、环和自依赖给出诊断。
逐个 Attach 成功后才发布该模块命令。冷启动失败保留 Attached=false 和原因并继续其他模块；
整轮处理结束后置 IsReady，通知已声明的域.host.ready。单包热安装不发送整轮通知。
Attach 中仍不应假设整个宿主已经就绪。

验收：`ModuleStartupOrderTests.ReadinessOnlyRisesAfterEveryModuleIsAttached`。

### REQ-MOD-010 接入失败与同包修复

Attach 抛异常时，其显式注册及反射命令均不得进入可执行注册表。热安装接入失败必须回滚。
同包幂等成功要求内容校验一致且 Attached=true；未装载或不健康实例允许重新接入。

验收：`RuntimeModulePackageTests.FailedStartupPublishesNoCommandsAndIdenticalInstallCanRetry`。

### REQ-TXN-001 模块包事务与数据保护

在线安装、离线安装和移除区分准备、备份、就位、提交、回滚和需恢复阶段。
备份没有成功时不得删除原目标；新包就位后先从备份复制 data，旧数据保留到提交。
接入失败恢复原包和原始数据；恢复失败保留事务目录和备份并返回恢复路径。
提交后才清理旧包，清理失败报告残留路径且不撤销已提交结果。校验断言须覆盖完整载荷和数据。

### REQ-CLI-001 离线与运行时通道分离

Console CLI 的 --cli 固定离线组合，--runtime 只连接活宿主，不可达返回失败且不降级。
runtime 仅四条：vulcan.module.list/ready/reload/install；当前用户管道、挑战握手、实例身份与动作批准要求不变。
reload/install 要求 --approve。标准 JSON 回执保持单一对象，字段与退出码见消费合同。

### REQ-REL-001 进程内管线与发布事务

模块走 dev.start/submit/finish；宿主禁止走模块开发管线。发布引擎不以 PowerShell 为实现。
发布拒绝自替换；同版本正式包不可覆盖，工作区候选允许显式覆盖。旧快照不可变归档。
备份和就位分阶段；回滚失败保留备份，提交后清理失败仅报告残留。
CI 不发布、打标签或部署。
