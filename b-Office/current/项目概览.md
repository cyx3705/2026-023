# HistoryVulcan 项目概览

源码：**5.6.1**；冻结基线：**v5.4.0**。本仓是独立 Git 项目。

| 组件 | 职责 |
| --- | --- |
| Core | 模块入口与上下文（含唯一前端登记）、命令注册/执行、日志与存储合同 |
| Services | 完整包发现、装卸与事务；公开面只留模块测试装载器、发现记录、模块元信息与命令目录 DTO，设置/日志、开发和发布引擎为内部实现 |
| ServiceHost | 组合根、运行循环、缺省确认、离线 CLI 与当前用户 runtime 管道；程序集没有公开类型 |
| App / Cli | WinExe 与同目录 Console CLI 入口 |
| DemoModule | 本仓最小接入示例，不进正式运行区 |
| HistoryAurora | 桌面界面、布局和确认交互；独立模块，经 RegisterFrontend 登记为宿主唯一前端 |
| HistoryMercury | 命令工作台与快捷键；独立模块 |
| HistoryPortunus | Web/MCP 协议、监听、鉴权和会话；独立模块 |

宿主维护通用生命周期与命令集成，不提供模块领域抽象。WPF 解析、线程编组和可回收装载仍属宿主职责；界面线程、确认交互与界面生命周期中继由唯一登记的前端提供，宿主总线在交给模块前封口。

运行主线：固定 Modules 完整包 → 校验与发现 → 按 dependsOn 接入并发布成功模块的命令 → 整轮就绪通知。安装/移除使用事务保护旧包和 data；失败语义见[技术合同](技术合同.md)。

`--cli` 在离线组合执行，`--runtime` 连接活宿主。模块开发流程见[开发手册](../package/模块开发手册.md)，宿主发布及真机检查见[验证合同](验证合同.md)。
