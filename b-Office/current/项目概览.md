# HistoryVulcan 项目概览

更新日期：2026-08-14

## 一句话定义

HistoryVulcan 是 OneHistory 的通用 .NET 8 / WPF 壳：命令、停靠、日志、设置、模块、MCP/Web
与服务生命周期。它是**独立 git 仓库**里的一个编号项目，不是共享裸仓上的一条分支。

## 项目库编码（一项目一仓）

- 本目录 `2026-023-HistoryVulcan` 本身就是仓库；默认分支是 `main`。平行开发在本仓内开分支。
- 邻接的 `YYYY-NNN-*` 目录是别的项目、别的仓库。不得把它们当成同一 Git 身份下的 worktree 或兄弟分支。
- 模块发现只认文件系统：向上找到含多个编号项目目录的项目库根，再枚举各项目的 `z-*`。
  发现不依赖裸仓、不依赖 `HistoryVesta.git`、不读取兄弟仓的 git 对象。
- CI 与门禁只验证本仓库。兄弟项目在本地磁盘上存在，不表示它们属于本仓，也不得用跨仓 `ProjectReference`。

## 目标与边界

### 目标

- 提供可运行、可测试、可回滚的独立宿主，并为嵌入式消费保留固定公共合同。
- 单一窗口承载中央工作区与四边工具页；布局持久化；模块可热重载。
- 默认最小能力、安全边界、公开 API 基线守住冻结契约。

### 范围

- 单 EXE 双进程宿主，以及 `Core`、`Services`、`Shell`、`ServiceHost` 四个嵌入式合同。
- 根级 `b-Code-Tests`、隔离包消费测试和示例模块。
- 消费合同编辑源、候选打包、正式归档及 `z-HistoryVulcan` 当前快照。

### 非目标

- 不承载 Janus、Mercury 或其他模块的业务与数据模型。
- 不提供已删除的数据库服务、通用表窗口或 `db.*`。
- CI 不发布、不打标签、不部署。
- 不把项目库 Git 治理做成宿主职责（那是 Janus，且存储引擎正在换到一项目一仓）。

## 当前版本

源码与正式 Z 均为 **3.11.5**。`HistoryVulcan.Core` 公开面自 3.9.0 起冻结。
V3 历史冻结标签仍是 `v3.0.3`，只约束 3.0.x 维护分支。

## 发布（Diana 管线已接管）

本项目不再手写第二套发布手册。权威入口：

```powershell
# 候选（构建、门禁、写入 b-Publish/current，不提升 Z）
..\2026-019-HistoryDiana\b-Code\Publish-OneHistoryModule.ps1 -Module HistoryVulcan

# 正式提升（先部署后提交：允许脏工作树；须用户批准）
..\2026-019-HistoryDiana\b-Code\Publish-OneHistoryModule.ps1 -Module HistoryVulcan -Publish
```

本仓 `Build-HistoryVulcanPackage.ps1` 只生成审核候选，不调用 `dotnet pack`，不写 Z，不 commit / tag / push。
消费文档只改 `b-Office/package/`；写入 `z-HistoryVulcan/docs/` 由 Diana 编排。
不得手改 `b-Publish/` 正式归档或 `z-HistoryVulcan/`。

嵌入框架的体系外消费方若仍用四包，必须同一版本；宿主自身以 Z 里的 EXE 为准，不发布到 NuGet.org。
回滚：把消费方锁回上一正式版本，或从 `b-Publish/history/<版本>/` 取当时快照；用户数据目录先备份。

## 命令总线运行事实

独立宿主里 MCP、非 UI 模块和命令权威表都在后台；前端 `EnableMcp=false`，经 loopback 转发。
`tools/list` / `tools/call` 每次读后台注册表，热重载不换端口。
已认证的本机 `loopback-shell` 不消耗公网 `web.ratelimit`；普通 Web / 远端会话仍限流，429 必须带 `Retry-After`。

仍开放的风险（不是未修缺陷，是已知边界）：

1. `CommandBus` 没有全局并发上限；削峰靠公网限流和 MCP 会话，不是完整背压。
2. `McpExposurePolicy` 只支持一个权威 `ModuleHost`，没有同进程多租户。
3. 前端 WebSocket 只在连接时发布 UI 命令目录；运行期新增前端命令需重连。后台模块命令不受此限。

专项测试：`VERIFY-MCP-BUS`（`McpCommandBusIntegrationTests`、`StandaloneMcpOwnershipTests`、`WebGatewayRateLimitTests`）。

## 关键约束

- 平台：Windows、WPF、`net8.0` / `net8.0-windows`。SDK 以根 `global.json` 为准。
- 独立可执行宿主 `EnableModules=true`；包消费方默认 `EnableMcp=false`、`EnableModules=false`。
- MCP 须描述符显式允许；敏感值不得进日志、历史或未授权响应。
