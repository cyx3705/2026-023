# HistoryVulcan 命令入口审计

适用源码：5.4.0。本表只审计宿主入口；界面按钮、停靠、控制台交互由 Aurora/Mercury 的各自合同验收。

| 宿主入口 | 执行归属 | 无可用消费方时 |
| --- | --- | --- |
| vulcan.app.show/hide/close/focusconsole | ServiceCommands 转交 RegisterFrontend 登记的唯一前端 | 明确报告界面未装载 |
| vulcan.app.quit、vulcan.svc.* | 宿主生命周期；quit 先请前端关窗，停止请求通过当前组合回调 | 未接回调时报告失败；无前端时直接停机 |
| vulcan.app.get/set | 宿主通用配置 | 保持存储、敏感回执遮蔽 |
| vulcan.module.list/ready | 模块状态与失败诊断 | 空列表仍可查询 |
| vulcan.module.reload/install | 模块生命周期与包事务 | 接入失败返回失败并恢复原包 |
| vulcan.module.unload/remove/uninstall | 内存卸载或持久移除；卸下模块时一并撤销其前端登记 | 指定目标不存在时失败；不误伤邻居 |
| vulcan.module.roots/open | 固定运行区查询/打开 | roots 拒绝修改，open 仅在目录存在时执行 |
| vulcan.command.* | 实际注册表的目录投影 | 不合成迁出模块的命令 |
| vulcan.dev.* | 模块专用开发管线 | 宿主目标被拒绝 |
| vulcan.release.* / worktree.* | 内部开发发布引擎 | 受 CLI 暴露策略约束 |

所有要求确认的命令默认拒绝；登记了前端时由前端确认，前端撤销后回落到宿主缺省拒绝。runtime CLI 只允许 list/ready/reload/install，
并非上述整个宿主目录的通用远程执行入口。MCP/Web 的工具投影与确认边界由 Portunus 维护。

验收：HostConfirmationTests、FrontendRegistrationTests、CommandTaxonomyContractTests、CommandLineEntryTests、RuntimePipeServerTests。
历史 UI 审计与已移出命令表见[清理前归档](../history/5.2.1-现行合同归档.md)。
